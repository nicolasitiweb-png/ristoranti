# LUME — Ristorante

Sito vetrina concept per **LUME**, ristorante italiano contemporaneo immaginario.

## Stack
- HTML5 semantico
- CSS responsive, senza framework
- JavaScript vanilla
- Google Fonts
- Fotografie remote da Unsplash

## Pubblicazione
Il progetto è pensato per essere pubblicato direttamente con GitHub Pages come sito statico.

> LUME è un concept fittizio: indirizzo, contatti e menu sono inventati.
